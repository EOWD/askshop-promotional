# tapmerce.com — marketing site

Next.js 16 (App Router) + Tailwind 4 marketing site for **Tapmerce**, the mobile AI
commerce platform for Shopify stores. Statically generated: home, features, pricing,
about, blog, competitor comparisons, privacy, terms, DPA and imprint.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # static production build
pnpm lint
```

## Identity and contact

Every name, email address and brand string on the site comes from `src/lib/site.ts`.
Change the contact email, founder or legal operator there and it propagates to the
header, footer, about page, imprint, legal pages, waitlist and structured data.

- Contact currently routes to the founder's inbox because `tapmerce.com` has no MX
  records yet. Swap `site.contact.email` when the mailbox exists.
- Fill `site.legal.address` before serving EU visitors in production (Imprint, § 5 DDG).
- The waitlist opens a pre-filled email. Replace `submitWaitlist` in `src/app/page.tsx`
  with a form backend when one exists.

## Deploy

The domain is on Cloudflare DNS with no records. Deploy the app (Vercel or any Node
host), then point `tapmerce.com` and `www` at it. `robots.txt`, `sitemap.xml` and the
Open Graph image are generated by the app.
